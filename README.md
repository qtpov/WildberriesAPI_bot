Wildberries API Bot & Service

Проект, выполненный в рамках тестового задания, демонстрирующий первые шаги работы с внешним API (Wildberries), асинхронным Python, FastAPI, Telegram-ботом и базой данных.

Проект состоит из:
- FastAPI-сервиса для работы с товарами WB
- Telegram-бота для взаимодействия с пользователем
- фонового планировщика для обновления данных товаров

🔍 Основной функционал
📦 Работа с Wildberries API

Получение данных о товаре по артикулу
Парсинг:
- названия товара
- цены
- рейтинга
- общего количества на складах
- Асинхронные HTTP-запросы через aiohttp
- 🗄 Работа с базой данных

Асинхронный SQLAlchemy (AsyncSession)

Хранение товаров в БД:
- artikul
- name
- price
- rating
- stock_quantity

Проверка наличия товара перед добавлением

🤖 Telegram-бот (aiogram 3)
Бот позволяет:
- 🔎 Получать данные о товаре по артикулу
- ➕ Добавлять товар в базу данных (админ-действие)
- ⭐ Подписываться на товар для отслеживания изменений

Используется:

- FSM (Finite State Machine)
- Inline-кнопки
- Асинхронная работа с БД
- ⏱ Фоновое обновление данных
- Используется APScheduler
- Возможность подписки на товар
- Автоматическое обновление данных каждые 30 минут

Задачи регистрируются динамически по артикулу

🌐 FastAPI эндпоинты

➕ Добавление товара

POST /api/v1/products

🔔 Подписка на обновление товара

GET /api/v1/subscribe/{artikul}

Запускает фоновое обновление данных товара каждые 30 минут.

🤖 Команды Telegram-бота
- /start — стартовое меню
- Получить данные по товару
- Добавить товар в базу
- Подписаться на товар
Бот работает через inline-кнопки и FSM-состояния.
